📖 Sobre o Projeto

Este tradutor foi desenvolvido como parte da certificação AI-102 da Digital Innovation One (DIO), originalmente usando Azure AI. A versão atual demonstra o mesmo conceito com uma arquitetura multi-plataforma independente.

  • Modo Técnico — preserve blocos de código, `variáveis`, URLs e termos técnicos (API, Docker, Python, Azure, Kubernetes…)
  • Suporte a Markdown — cabeçalhos, listas, negrito, itálico e blocos de código são preservados
  • +20 idiomas — Inglês, Português, Espanhol, Francês, Alemão, Japonês, Coreano, Árabe e mais
  • Atalho — pressione Ctrl+Enter para traduzir rapidamente

🛠 Stack & Diferenciais

  • Frontend: HTML5 + CSS3 + JavaScript puro — rodando no GitHub Pages, sem servidor
  • Python: CLI deep-translator + API FastAPI (deploy separado)
  • C#: CLI com .NET + MyMemory API
  • Tradução: Google Translate (via deep-translator) com fallback automático para MyMemory API
  • Preservação de ~150 termos técnicos, blocos de código, URLs e formatação
  • CI/CD: GitHub Actions → deploy automático no GitHub Pages
